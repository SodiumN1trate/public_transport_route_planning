# Public Transport Route Planning

Mans pirmais **Laravel projekts**, kas izstrādāts, apgūstot PHP Laravel ietvaru un REST API izstrādes pamatus.

Projekta uzdevums bija balstīts uz vienu no **SkillsLatvia Web tehnoloģiju konkursa uzdevumiem** un paredzēja izstrādāt sabiedriskā transporta maršrutu un pieturvietu pārvaldības sistēmas backend daļu.

## Funkcionalitāte

Izstrādāts REST API, kas nodrošina:

- Sabiedriskā transporta ierakstu pārvaldību.
- Pieturvietu izveidi, apskati, atjaunināšanu un dzēšanu.
- Transporta un pieturvietu savstarpējo relāciju izmantošanu.
- Ievades datu validāciju.
- Strukturētas JSON atbildes.

## Izmantotās tehnoloģijas

- PHP
- Laravel 8
- REST API
- Eloquent ORM
- Laravel Form Requests
- Laravel API Resources
- SQL datubāze

## Par projektu
Šis ir mācību projekts, kura galvenais mērķis bija praktiski apgūt Laravel arhitektūru, API izstrādi, datubāzes relācijas un datu validāciju.
